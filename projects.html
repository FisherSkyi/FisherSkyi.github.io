Soulless Knight: An iOS Dungeon Game

Team-developed for CS3217 Software Engineering on Modern Platforms at NUS, then showcased at NUS STePS 2026.

The project website is here.

The game follows an Entity-Component-System architecture and received 86 audience votes at the showcase.

I led work on the weapon and projectile systems, and also designed the command pattern used for input and game actions.

SkyPeggle: A Game with its own Engine

A solo iPad game project for CS3217, built in Swift with a custom physics engine, UIKit views, and level designer tooling.

The demo is available here.

Tech Stack & Skills

  • Swift + UIKit with dependency injection, persistent JSON levels, and state-driven rendering helpers.
  • Custom PhysicsEngine with circle-OBB collision, chain reactions, and gameplay callbacks.
